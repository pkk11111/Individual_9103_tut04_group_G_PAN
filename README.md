2. Individual Animation Approach

For my individual task, I animated the group’s static composition by introducing an organic floating motion using Perlin noise and randomness.

While the group version contained:

    static wheel positions,

    mathematically defined curves,

    and local sine-based bead oscillations,

my individual version transforms the scene into a living, drifting system.

I chose the method Perlin noise and randomness, and used it to animate the following elements:

A. Wheels (main component)

Every wheel receives:

    two unique Perlin noise seeds,

    a random floating radius,

    time-varying offsets (offsetX, offsetY) generated by noise.

This produces a smooth, continuous drifting motion, similar to objects moving inside a fluid or wind field.

B. Connector curves

Each connector receives:

    its own pair of noise seeds,

    a Perlin-noise offset applied to the curve’s control point.

Combined with the floating wheels, connectors appear like soft, flexible lines affected by unseen forces.

These animations make my version different from my group members, who focused on other aspects such as color variation, timing, or interactive behaviour.

3. Animation Method Chosen

Perlin Noise + Randomness

I deliberately avoided user input, audio, and timers to keep the system purely driven by:

    noise() — for smooth, natural motion

    random() — for variety, seeds, and behaviour differences between wheels/curves

This ensures my animation has a strong identity within the group.

6. Technical Explanation
A. Noise-Driven Wheel Motion

Each wheel is assigned two noise seeds and a random floating radius:
    this.floatNoiseX = random(1000);
    this.floatNoiseY = random(2000);
    this.floatRadius = random(10, 30);

During each update:
    const t = frameCount * 0.005;
    const nx = noise(this.floatNoiseX + t);
    const ny = noise(this.floatNoiseY + t);

    this.offsetX = map(nx, 0, 1, -this.floatRadius, this.floatRadius);
    this.offsetY = map(ny, 0, 1, -this.floatRadius, this.floatRadius);

B. Connectors Follow the Animated Wheels
    The helper function:
    getCurrentPosition() {
    return createVector(this.x + this.offsetX, this.y + this.offsetY);
    }
Connectors use this updated position to remain attached to floating wheels.

C. Noise-Based Curve Wobble
Connector control points drift using noise:
    const t = frameCount * 0.01;
    const nx = noise(this.noiseSeedX + t);
    const ny = noise(this.noiseSeedY + t);

    this.ctrlOffsetX = map(nx, 0, 1, -20, 20);
    this.ctrlOffsetY = map(ny, 0, 1, -20, 20);
This causes subtle, organic curve movement.

D. Randomness
Random is used to generate:
    individual seeds,
    floating radii,
    variations in wobble strength.
This ensures that each element behaves uniquely.
